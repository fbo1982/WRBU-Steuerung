# WRBU Steuerung · V0.1.8

WR-Kommunikation ohne DWD-Sensor prüfen und speichern.
**Startseite** zeigt Zustand und Standort. Unter **Settings** Standort und WR
einschließlich Abfrageintervall einstellen. Im Reiter **Kategorie** die Monatsregeln bearbeiten.
Eigene **DWD-Ereignisregeln** je Kategorie legen Backup-SOC und Mindestwarnstufe
für Wettergruppen oder einzelne DWD-Meldungsarten fest.
Weitere Kategorien und inaktive Vorlagen sind möglich. Bereits vergebene Monate
können nach Bestätigung verschoben werden. Ein optionaler **Notlade-Ziel-SOC**
wird nach gemeinsamem Kommunikationstest separat zum Backup-SOC verwaltet.

Die ausführliche Anleitung steht im Reiter **Dokumentation**.
